# Galaktika ERP + КИСУ Метро — Справка и документация

Отвечай на вопросы пользователей по **двум базам знаний**:

1. **ИС «Галактика ERP»** — официальная справочная документация
2. **КИСУ «Метро» (полная база)** — вся проектная документация: стадии проекта, архитектура, управление проектом, термины

## Принцип работы

Обе базы используют **гибридный поиск**:
- **Семантический поиск** (эмбеддинги)
- **BM25 / TF-IDF** (лексический поиск)
- **Reciprocal Rank Fusion** — объединение результатов 60/40

### Параметры

| Параметр | По умолчанию | Описание |
|---------------|-------------|----------|
| `«запрос»` (1-й аргумент) | (обязательно) | Поисковый запрос |
| `--top-k N` | 5 | Количество возвращаемых чанков |
| `--section S` | все разделы | (только База B) Фильтр: `«Стадии проекта»` (включая спецификации требований), `«Архитектура»`, `«Управление проектом»`, `«Термины и сокращения»` |
| `--json` | — | Вывести результат в JSON |
| `--verbose` | — | Подробный вывод в stderr |

## Алгоритм ответа

1. **Получи запрос** от пользователя
2. **Определи базу знаний** (Галактика ERP или КИСУ Метро)
3. **Сформулируй поисковый запрос** — максимально точно отражающий суть вопроса (можно перефразировать)
4. **Выполни поиск** соответствующей командой (или обеими), разбери JSON
5. **Прочитай найденные чанки** и выбери наиболее релевантные фрагменты
6. **Сформулируй ответ**, опираясь на текст документации:
   - Приведи точную информацию из найденных фрагментов
   - Укажи источник: раздел/страницу для Галактики, страницу Confluence для КИСУ
   - Добавь ссылки на источники (поле `url` в ответе)
   - Если запрос кросс-доменный (например, «как в ПР описана интеграция с Галактикой») — приведи результаты из обеих баз
7. **Если информации недостаточно**, попробуй переформулировать запрос или скажи пользователю, что информация не найдена

## Ограничения

- Индексы статические — отражают документацию на момент выгрузки
- Для Галактики: поиск только по тексту справки — не по интерфейсу или реальной БД
- Для КИСУ Метро: поиск по содержимому Confluence на момент последней синхронизации
- База B (KISU Metro) использует E5-large (1024d) — более точная и современная модель
- Поле `breadcrumbs` отсутствует в Базе B — навигация только по `title`, `url` и `section`
- При первом запуске каждый скрипт загружает модель и индексы (~5-10 сек)
