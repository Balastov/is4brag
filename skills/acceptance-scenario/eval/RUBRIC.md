# Рубрика пилотов сценария приёмки

Считаем только **шаги**: секции 6 (шаги сценария) и 7 (негативные проверки).
Пустые строки шаблона не считаются.

## Автоматически (`score_scenario.py`)

| Метка | Правило |
|---|---|
| `with_page_id` | В колонке Источник есть `page_id` из 6+ цифр |
| `explicit_gap` | В строке есть `НЕ НАЙДЕНО В ИСТОЧНИКАХ` |
| `ungrounded_candidate` | Есть действие/ожидание, нет `page_id` и это не explicit gap |

`steps_with_page_id_pct = 100 * with_page_id / total_steps`

## Вручную (обязательно)

Для каждого шага проставьте одну метку:

| Метка | Когда |
|---|---|
| `grounded` | Утверждение следует из цитаты/страницы с указанным `page_id` |
| `gap_ok` | Честно `НЕ НАЙДЕНО` |
| `hallucinated` | Конкретный факт (роль, статус, шаг БП, код ФТ, ожидаемый UI) **не** следует из источника, либо источника нет |

`hallucinated_steps_pct = 100 * hallucinated / total_steps`

Цели первой волны: **≥80% шагов с page_id**, **≤10% hallucinated**.

Не штрафуем короткий сценарий с большим блоком «Пробелы», если модель не додумала шаги.
